# Neon Rebound

A sleek two-player browser-based Pong duel featuring refined neon visuals, ultra-responsive controls, and fast-paced matches designed for quick play sessions.

## Play
[![GitHub Pages](https://img.shields.io/badge/Live_Demo-Online-brightgreen?style=flat-square&logo=github)](https://acswyss-yi.github.io/neon-rebound/)
Open `index.html` in any modern browser.

## Controls
- Player One: W / S
- Player Two: ↑ / ↓
- Space: Pause
- R: Restart

## Notes
First player to score 7 points wins.
